# 训练指标阅读指南

适用于项目训练入口 `python -m g1.rl train` 的 TensorBoard/W&B 指标，覆盖 Phase 1/2/3。
本文数值以当前默认配置为准；修改回合时长、误差阈值或奖励权重后，应按实际配置判断。

## TensorBoard：推荐从分组对比面板开始

在 TensorBoard 顶部选择 **Custom Scalars**（可能位于面板下拉菜单中）。先只看一次训练，
默认展开的“01 总览”只有 6 张图，覆盖任务完成、生存、跟踪误差和实际训练样本分配。
每张图叠加四种模式的同一指标，直接比较曲线，无需在几十张单独卡片之间来回寻找。

**四模式分色**：在左侧取消勾选原始训练 run，只勾选该次训练目录下
`mode_comparison/stand`、`mode_comparison/squat`、`mode_comparison/walk`、
`mode_comparison/squat_walk` 和 `mode_comparison/context`。
四种模式通过各自的展示 run 获得不同颜色，同一模式在各张图中保持同色；
`context` 提供公共采样范围、扰动配置和排除回合数。
这些展示 run 来自同一个模型的同一批统计，不代表五次独立训练。

| 分组 | 用途 |
| --- | --- |
| 01 总览 | 日常判断模型是否进步；默认展开。 |
| 02 跟踪详情 | 定位高度、速度、转向或骨盆偏移的问题。 |
| 03 样本与有效性 | 判断模式是否缺少样本、回合是否被排除。 |
| 04 生存与终止 | 比较各模式时长、超时和具体失败原因。 |
| 05 扰动暴露 | 对照实际扰动次数、暴露率和配置强度。 |
| 06 任务难度 | 比较实际指令强度与当前采样范围。 |

其余组默认折叠，发现异常后再展开。骨盆跟踪只对比站立、下蹲；不同量纲不会混在同一张图中。
跨运行对比时少量选择训练，避免四种模式乘上多次运行后曲线过密。
原始指标仍可在 Scalars/Time Series 中逐项查询，标签与数值不变。

新启动的训练自动生成分组布局和分色视图。已有日志可补充分色视图，然后等待 TensorBoard 重新加载或刷新页面：

```powershell
uv run --no-sync python -m g1.rl.tensorboard_layout --logdir logs/rsl_rl/g1_flat --mode-colors
```

也可将 `--logdir` 指向单次运行目录。此操作添加展示副本，保留原始标签、数值、迭代号和历史时间，
不会改写源事件文件；重复执行会跳过已有数据点。旧进程仍在训练时，可再次执行以补充后续数据；
新启动的训练会实时更新视图。额外磁盘占用只来自这些诊断指标的副本，不复制模型文件或创建 W&B 实验。

也可以用单次运行的 `mode_comparison` 作为 TensorBoard 的 `--logdir`，让左侧只出现该次训练的展示 run。
若在原始日志根目录下查看，切勿同时选中原始 run 和它的展示 run，以免同一数据叠加两次。

TensorBoard 的 [Custom Scalars](https://github.com/tensorflow/tensorboard/blob/master/tensorboard/plugins/custom_scalar/README.md)
按 run 分配颜色；同一 run 内不同 tag 只区分标记形状。
[布局接口](https://github.com/tensorflow/tensorboard/blob/master/tensorboard/plugins/custom_scalar/layout.proto)
不能指定色值、亮度或饱和度，因此用不同模式的展示 run 分色。
具体颜色由 TensorBoard 分配，跨训练运行或改变日志加载范围后可能变化。

下面按界面顺序说明全部 35 张图，**图表名称与面板中文标题一致**。后文的英文指标名用于查询原始日志。
四种模式分别为站立、下蹲、行走、蹲走；比较曲线时先核对图例中的模式。

阅读这些面板时，先统一三个判断前提：

- **先确认样本量**：回合统计只纳入完整观测、自然结束且回合内模式未变化的有效回合，包含失败回合。
  没有有效结束回合时，成功率与回合误差不产生新点；曲线缺点或平滑连线不能当作新测量结果。
- **先对齐任务条件**：同一模式跨时间、跨检查点比较时，同时看目标难度与扰动条件。
  四种模式的任务本身不同，某模式误差更低并不直接代表能力更强。
- **箭头表示改善方向**：`↑` 通常希望升高，`↓` 通常希望降低；未标箭头的样本量、配置和难度图没有统一的优劣方向。
  比例取值为 0～1，0.8 表示 80%；计数与均值按本次日志窗口统计，配置边界则记录日志时刻的值。

回合类指标纳入本窗口结束的回合，其误差覆盖整个回合的执行过程；
实际控制步数、实际目标均值与扰动暴露则统计本窗口内发生的数据。

### 01 总览

用于先判断各模式是否能存活并完成任务，再决定展开哪一组详情。

| 图表名称 | 指标含义 | 对比观察与判断 |
| --- | --- | --- |
| 联合成功率 ↑ | 有效结束回合中，正常超时、没有失败且回合平均高度与速度误差均达标的比例；站立、下蹲还要求回合平均骨盆水平误差达标。速度条件同时包含平面速度与转向。 | 在难度、扰动和样本量相近时，持续升高表示完整任务完成能力改善。若失败率已低但它仍低，展开“02 跟踪详情”定位未达标通道。 |
| 失败率 ↓ | 有效结束回合中，触发任意非超时终止条件的回合比例。 | 持续降低通常表示更稳定；单个模式明显升高时，展开“04 生存与终止”查原因，同时核对任务是否变难。 |
| 存活比例 ↑ | 每个有效回合的实际控制步数除以最大回合步数，截到 1 后再对回合平均。 | 趋近 1 表示存活时长接近上限。若它很高但失败率仍高，可能在回合末段失稳；结合正常超时率确认。 |
| 高度误差 (m) ↓ | 每个有效回合中，骨盆实际世界高度与目标高度的绝对误差均值，再对回合等权平均。 | 同等蹲深和目标变化条件下越低越好。下蹲、蹲走误差升高时，先看“实际高度目标偏移 (m)”和“高度采样边界 (m)”是否同时改变。 |
| 平面速度误差 (m/s) ↓ | 每个有效回合中，机体系前后、侧向速度误差的二维范数均值，再对回合等权平均。 | 站立、下蹲中主要反映非期望平面漂移；行走、蹲走中反映速度跟踪偏差。比较运动模式时，应同时看“实际目标速度 (m/s)”。 |
| 实际训练步数占比 | 该模式本窗口实际观测控制步数占全部模式控制步数的比例，包含未结束及被排除回合已执行的步数。 | 用于判断模型实际获得多少该模式经验，没有固定的最优比例。占比很低时，对照“新回合采样概率”和“回合时长 (s) ↑”，区分分配减少与频繁失败。 |

建议按“失败率 ↓ → 存活比例 ↑ → 联合成功率 ↑ → 两项误差”的顺序看。
失败率下降、存活比例升高，但联合成功率仍低，通常应继续排查跟踪能力；
若性能变化伴随实际训练步数占比、任务难度或扰动变化，先解释条件变化，再判断是否退步。
联合成功率直接统计同一回合是否全部达标，不是几项成功率相乘。

### 02 跟踪详情

用于区分高度、平面速度、转向和骨盆水平控制中的问题。两张骨盆图只比较站立、下蹲。

| 图表名称 | 指标含义 | 对比观察与判断 |
| --- | --- | --- |
| 转向误差 (rad/s) ↓ | 每个有效回合中，机体系 yaw 角速度与目标角速度之差的绝对值均值，再对回合等权平均。 | 静止模式中偏高提示非期望转动；运动模式中偏高提示转向跟踪不足。结合“实际目标转向 (rad/s)”比较相近转向要求下的表现。 |
| 骨盆水平误差 (m) ↓ | 有效结束回合内，骨盆相对双踝水平参考系的实际位置与目标偏移之间的二维距离，按有效控制步加权平均。 | 同等骨盆偏移目标下越低越好。升高时对照骨盆前后、左右采样边界；它衡量骨盆目标跟踪，不直接衡量质量加权重心或支撑稳定裕度。 |
| 高度跟踪成功率 ↑ | 回合平均高度误差严格小于 0.03 m 的有效结束回合比例。 | 应与“高度误差 (m) ↓”一起改善。它不要求正常超时，若成功率高而失败率也高，说明短回合可能跟踪尚可，但仍不能稳定完成任务。 |
| 速度跟踪成功率 ↑ | 回合平均平面速度误差 < 0.5 m/s，且回合平均转向误差 < 0.4 rad/s 的有效结束回合比例。 | 同时要求两个速度通道达标，但当前阈值对低速任务较宽松。即使接近 1，也要继续看平面速度与转向误差是否降低；同样不要求正常超时。 |
| 骨盆逐步成功率 ↑ | 有效结束回合中，骨盆水平误差严格小于 0.02 m 的有效控制步占比。 | 与“骨盆水平误差 (m) ↓”一起看：均值降低但达标步占比仍低，可能有较多时刻略超阈值。它按控制步计，不是回合成功率，也不要求完整存活。 |

若联合成功率低，先找这里偏低的跟踪成功率，再看对应连续误差。
若各项跟踪成功率都高，仍需检查正常超时率，以及多个条件能否在同一个回合同时满足。
联合成功的骨盆条件是**回合平均误差 < 0.02 m**，与“骨盆逐步成功率 ↑”的逐步判定不同。

### 03 样本与有效性

用于确认曲线是否有足够数据，以及某模式是否实际获得训练时间。这一组没有“越高一定越好”的指标。

| 图表名称 | 指标含义 | 对比观察与判断 |
| --- | --- | --- |
| 有效结束回合数 | 本窗口该模式满足统计条件的结束回合数，是回合成功率与失败率的分母。 | 为 0 时不判断新的回合性能；样本很少时，比例大幅波动可能由少数回合造成。数量高也可能只是短回合频繁失败，需一起看回合时长。 |
| 有效结束回合占比 | 该模式有效结束回合数除以所有模式有效结束回合数。 | 反映本窗口结束回合的构成。它不等于训练控制步占比；比例切换或不同模式存活时长不同时，应跨多个窗口观察。所有模式都无有效回合时不输出。 |
| 实际控制步数 | 本窗口该模式实际观测的控制步总数，包含未结束回合和被排除回合已执行的步数。 | 判断是否真的收集到该模式经验。步数增加但没有有效结束回合时，先看回合是否尚未结束，以及“排除回合数”是否异常。 |
| 新回合采样概率 | 日志时刻为新回合选择该模式的归一化概率。 | 表示分配计划。与“实际训练步数占比”对照，判断低占比来自计划分配还是较短存活；概率变化后，旧回合结束需要时间，实际占比可能延迟响应。 |
| 排除回合数 | 公共图中三条曲线分别统计：执行过动作但未自然终止便重置的回合、观测不完整的自然结束回合、完整观测但中途切换模式的自然结束回合。三类互斥。 | 普通无人值守训练中，人工重置和模式切换通常应为 0；初始随机回合年龄可能造成首批部分回合。之后持续升高时，先检查重置、计数或人工控制，再解释性能曲线。 |

最容易混淆的是三种分配口径：新回合采样概率是计划，有效结束回合占比是结束回合构成，
实际训练步数占比才是已观测控制步的分配。
当某模式采样概率稳定、实际步数占比偏低且回合很短时，应优先处理频繁失败导致的经验不足。
排除回合不进入回合性能统计，但其已执行控制步仍计入实际样本量。

### 04 生存与终止

用于解释总览中的失败率。当前默认完整回合为 6 s，四张具体终止图的纵轴都是有效结束回合比例。

| 图表名称 | 指标含义 | 对比观察与判断 |
| --- | --- | --- |
| 回合时长 (s) ↑ | 有效结束回合实际执行时长的均值。 | 向 6 s 靠近通常表示存活改善；明显变短时查具体终止原因。接近 6 s 仍需结合正常超时率，确认是否在末段失败。 |
| 正常超时率 ↑ | 有效结束回合中，到达时限且没有任何失败条件的回合比例。 | 趋近 1 表示更经常完整存活；若它高而联合成功率低，应转到“02 跟踪详情”检查任务精度。 |
| 躯干接触终止 ↓ | 有效结束回合中，躯干接触达到非法接触终止条件的比例。 | 升高时回放检查躯干落地或碰撞过程；与姿态异常、高度不足一起看，可帮助识别失稳后的接触。数值是回合比例，不是接触力。 |
| 膝部接触终止 ↓ | 有效结束回合中，膝部接触达到非法接触终止条件的比例。 | 下蹲、蹲走中升高时，重点核对蹲深与落膝过程；也可能是整体跌倒后的结果，需结合其他终止项和回放。 |
| 姿态异常终止 ↓ | 有效结束回合中，机体倾斜超过配置终止阈值的比例。 | 升高时对照目标转向、速度和扰动变化，检查姿态控制与受扰恢复。它记录终止阈值触发，不描述全部轻微晃动。 |
| 高度不足终止 ↓ | 有效结束回合中，骨盆高度低于最低允许值的比例。 | 升高时检查塌腿、深蹲控制和跌倒过程，同时看实际高度目标与采样下界，区分任务变深与能力退化。 |

失败率与正常超时率覆盖有效回合的两类结果，二者之和应接近 1；
联合成功率应不高于正常超时率。
一个回合可以同时触发多种失败条件，所以四张具体终止图的比例不能直接相加得到失败率。
多项同时升高时，回放中的触发顺序比单看最大一项更有助于定位原因。

### 05 扰动暴露

用于判断各模式是否真正经历了上肢扰动，以及当时的扰动目标范围有多大。
这些图本身没有统一的优劣方向，应与生存和任务完成情况一起比较。

| 图表名称 | 指标含义 | 对比观察与判断 |
| --- | --- | --- |
| 实际扰动次数 | 本窗口该模式中，上肢随机目标事件触发的环境次数；一次事件同时更新双臂和腰部，计一次。 | 次数低时，先核对实际控制步数、回合时长和事件是否启用。次数多也可能只是该模式样本更多，不能单独用来比较扰动强度或鲁棒性。 |
| 实际扰动暴露率 (Hz) | 实际扰动次数除以该模式本窗口累计观测控制秒数，合并所有并行环境计算。 | 用于在样本量不同的模式间比较触发频度，需跨多个窗口观察。暴露率相近且扰动比例相近时，再比较失败率和联合成功率，结论更可靠。 |
| 实际双臂扰动比例 | 本窗口实际触发事件所使用的双臂扰动比例均值，按触发次数平均；无触发事件时不输出。 | 越大表示采样关节目标的允许范围越宽。比较受扰表现时应对齐它；缺失表示没有可统计的事件，不能当作零扰动。它不是实际力矩或关节运动幅度。 |
| 配置扰动比例：双臂 / 腰部 | 公共图中两条曲线分别表示日志时刻双臂、腰部随机目标的配置比例，按默认关节角到各方向限位的余量缩放。 | 用于定位扰动范围变化的时间。升高后失败率暂时上升，可能是新难度尚未适应；配置切换附近，当前配置与事件均值可能短暂不同，应结合实际暴露与后续趋势判断。 |

可靠的鲁棒性改善，应体现为在暴露频度、扰动比例和任务目标相近时，失败率降低或联合成功率提高。
其余任务条件、暴露频度和样本量相近时，扰动比例提高后仍维持原有表现，也是适应更宽目标范围的积极信号。
未启用扰动事件时，配置曲线不输出；缺失不能直接按配置比例为 0 解读。
扰动触发与其后续影响可能跨窗口，同窗口曲线一起变化只能提供排查线索，不能直接确定因果。

### 06 任务难度

前三张图是各模式实际经历的目标均值，按本窗口控制步加权；后六张是公共配置的采样上下界。
边界图中的两条曲线分别为下界和上界，不是四种模式的实际目标极值。

| 图表名称 | 指标含义 | 对比观察与判断 |
| --- | --- | --- |
| 实际高度目标偏移 (m) | 高度指令相对默认站立骨盆高度的平均偏移。 | 越负通常表示蹲得越深；站立、行走通常为 0。下蹲或蹲走误差升高时，先看是否同时要求更深下蹲。均值不能反映最深目标，正负也可能抵消。 |
| 实际目标速度 (m/s) | 机体系前后、侧向速度指令二维范数的均值。 | 越大通常要求更快运动；比较平面速度误差时应对齐它。站立、下蹲目标通常为 0，此时平面速度误差主要反映漂移；本图不表示机器人实际速度。 |
| 实际目标转向 (rad/s) | yaw 角速度指令绝对值的均值。 | 越大通常要求更强的转向能力；转向误差随之升高时，先检查难度变化。使用绝对值，因此左右转向不会相互抵消。 |
| 高度采样边界 (m) | 高度偏移指令的公共采样上下界。 | 下界降低表示允许更深下蹲；对照实际高度目标与高度误差，判断性能变化是否伴随更深的任务。各模式不一定使用全部范围。 |
| 前后速度采样边界 (m/s) | 机体系前后速度指令的公共采样上下界。 | 范围扩大表示可采到更大的前进或后退速度；结合实际目标速度与平面速度误差，判断误差上升是否来自更宽任务范围。 |
| 侧向速度采样边界 (m/s) | 机体系侧向速度指令的公共采样上下界。 | 扩大后若运动模式误差或姿态终止增加，重点检查侧向运动回放。总平面速度误差没有区分前后和侧向，不能仅凭它确定侧向通道出问题。 |
| 转向采样边界 (rad/s) | yaw 角速度指令的公共采样上下界。 | 对照实际目标转向与转向误差；范围扩大但实际目标均值变化不大时，还应观察多个窗口，避免只按配置范围解释性能。 |
| 骨盆前后偏移边界 (m) | 相对双踝水平参考系的骨盆前后目标偏移范围，仅站立、下蹲采样。 | 允许偏移幅度扩大后，骨盆水平跟踪要求可能提高；若骨盆误差上升或逐步成功率下降，先核对该边界是否变化。 |
| 骨盆左右偏移边界 (m) | 同一参考系下的骨盆左右目标偏移范围，仅站立、下蹲采样。 | 用于解释横向骨盆跟踪难度变化；结合骨盆水平误差、逐步成功率和姿态终止观察，回放确认是否出现横向失稳。 |

这一组主要用来解释其他面板，不以数值升高或降低直接评判模型优劣。
蹲走的高度、速度还受高度—速度包络限制：蹲得更深时，允许的前进速度和转向范围可能缩小。
因此需要同时比较实际高度目标、实际目标速度和实际目标转向，不能仅凭公共采样边界判定四种模式难度相同。

## 快速判断：先回答五个问题

按四种模式分别查看：`stand`（站立）、`squat`（下蹲）、`walk`（行走）、`squat_walk`（蹲走）。
逐模式指标的完整路径为 `Performance/task_command/<mode>/<指标名>`。

| 顺序 | 问题 | 首先查看 | 判断方法 |
| --- | --- | --- | --- |
| 1 | 当前数据可信吗？ | 有效结束回合数、排除回合数 | 有效回合为 0 时不判断成功率；少量回合的突变先观察后续窗口。 |
| 2 | 能稳定存活吗？ | 失败率 ↓、存活比例 ↑ | 失败率应下降，存活比例应趋近 1；当前完整回合为 6 s。 |
| 3 | 活着时完成任务了吗？ | 联合成功率 ↑、各项误差 | 联合成功率应提高，误差应降低；仅存活或仅总奖励提高都不够。 |
| 4 | 是退步，还是任务变难？ | 实际训练步数占比、“05 扰动暴露”与“06 任务难度” | 先检查模式占比、蹲深、速度和扰动是否变化。 |
| 5 | 优化或动作哪里异常？ | `Loss/*`、`Policy/mean_std`、`Episode_Reward/*` | 结合学习率、损失、探索幅度和惩罚项定位，再用回放确认。 |

先看总览；需要确认样本量时展开“03 样本与有效性”，需要细分误差时展开“02 跟踪详情”。
既看平滑趋势，也看原始曲线，避免掩盖突发失败。

**可靠的改善信号**：在任务条件相近、样本充足时，多个窗口内失败率下降、联合成功率提高、相关误差降低。
不同模式、不同难度的总奖励不适合直接比较高低。

## 阅读前需要知道的统计口径

- 一个窗口对应一次 PPO 迭代日志；默认每环境采样 50 个控制步，控制频率 60 Hz。
  横轴是训练迭代号，续训后延续编号；不是各模式独立的训练次数。
- 回合性能纳入本窗口结束、从头到尾完整观测的自然终止回合，包含失败回合和终止帧。
  跨窗口回合仍计算整个回合的误差，再与其他完成回合等权平均。
- 步数和实际指令统计覆盖窗口内所有已观测控制步，包括未结束和部分回合，按控制步加权。
- 无有效回合时，成功率和回合误差不输出。缺失点不代表零误差、零成功率或满成功。
  新进程续训会重新收集窗口统计，计数不是历史累计训练量。
- 下文“趋近 1”“趋近 0”是改善方向，不是所有难度下都必须达到的验收标准。

## 1. 逐模式性能：能否存活并完成任务

本节指标均位于 `Performance/task_command/<mode>/`。

### 生存与联合成功

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `episode_length_s` | 有效回合执行时长的均值，单位 s。 | 当前上限 6 s；持续很短通常表示频繁失败。 |
| `survival_fraction` | 每回合执行步数 / 最大回合步数，截到 1 后平均。 | 越接近 1 越好；衡量存活时长，不是完整回合成功率。 |
| `failure_rate` | 有任意非超时终止条件的有效回合比例。 | 越低越好；结合终止原因定位问题。 |
| `timeout_rate` | 到达超时条件且没有失败条件的有效回合比例。 | 越高越好，但活到时限不等于跟踪正确。 |
| `joint_success_rate` | 同一回合正常超时、无失败、高度与速度跟踪均达标；站立/下蹲还要求骨盆 XY 平均误差达标。 | 优先用于综合判断任务完成能力，比单独跟踪成功率更严格。 |

联合成功率直接统计同一回合是否同时达标，不是各成功率相乘。
短回合即使跟踪误差很小，只要失败就不能算联合成功。

### 跟踪误差

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `error_height_m` | 每回合骨盆世界高度与当前目标的绝对误差均值，再对回合平均，m。 | 越低越好；包含目标变化后的过渡误差，比较时注意蹲深。 |
| `error_velocity_xy_mps` | 每回合机体系 XY 速度误差二范数均值，再对回合平均，m/s。 | 越低越好；静止模式中表示平面漂移，行走模式中表示速度跟踪误差。 |
| `error_yaw_radps` | 每回合机体系 yaw 角速度误差绝对值均值，再对回合平均，rad/s。 | 越低越好；静止模式表示非期望转动，转向时表示跟踪不足。 |
| `error_pelvis_xy_m` | 有效结束回合中，骨盆相对双踝水平参考系的 XY 误差范数，按有效控制步加权，m。 | 越低越好；仅站立/下蹲输出。不是质量加权重心误差或支撑稳定裕度。 |

前三项按回合等权，骨盆 XY 项按有效控制步加权。均值较低不能排除少量严重偏差或瞬时失稳。

### 跟踪成功率及当前阈值

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `height_tracking_success_rate` | 回合平均高度误差严格小于 0.03 m 的回合比例。 | 越高越好，但不要求完整存活。 |
| `velocity_tracking_success_rate` | 回合平均 XY 误差 < 0.5 m/s，且 yaw 误差 < 0.4 rad/s 的回合比例。 | 阈值对低速任务较宽松，必须同时看连续误差。 |
| `pelvis_step_success_rate` | 有效结束回合中，骨盆 XY 误差 < 0.02 m 的有效控制步比例。 | 越高越好；仅站立/下蹲输出，是逐步成功率。 |

`joint_success_rate` 沿用上述高度、速度阈值；骨盆条件使用**回合平均误差 < 0.02 m**。
这些成功率不要求所有时刻都在误差带内。速度成功率接近 1，也不代表低速行走已经精确。

### 失败原因

路径为 `Performance/task_command/<mode>/termination/<term>`，表示相应条件触发的有效回合比例。

| `<term>` | 定义 | 判断 |
| --- | --- | --- |
| `time_out` | 到达回合时限。 | 通常对应完整存活；同时失败时，不计入正常 timeout_rate。 |
| `base_contact` | 躯干触发非法接触。 | 升高时检查躯干落地或撞击。 |
| `knee_contact` | 膝部触发非法接触。 | 升高时检查蹲深、落膝和失稳过程。 |
| `bad_ori` | 机体倾斜超过终止阈值。 | 升高时检查姿态控制、转向和受扰恢复。 |
| `base_height_below_minimum` | 骨盆高度低于最低允许值。 | 升高时检查塌腿、深蹲能力或跌倒。 |

同一回合可触发多个条件，各原因比例之和不保证为 1。
某回合超时和失败同时发生时，该回合计入 failure_rate，不计入 timeout_rate，但仍计入原始 time_out 原因。

## 2. 样本与有效性：这个模式练了多少

以下指标仍使用逐模式前缀。

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `episode_count` | 本窗口有效结束回合数。 | 是回合成功率的分母；先确认数量，再解释比例。 |
| `episode_valid` | episode_count > 0 为 1，否则为 0。 | 仅表示有有效回合，不表示性能达标或统计可靠。 |
| `episode_share` | 该模式有效结束回合数 / 所有模式有效结束回合数。 | 是结束回合占比，不是新回合抽样频率；无有效回合时不输出。 |
| `step_count` | 本窗口该模式实际观测控制步数。 | 反映训练样本量，包含部分和未结束回合。 |
| `step_share` | 该模式控制步数 / 所有模式控制步数。 | 比配置比例更接近实际训练样本占比。 |
| `sampling_probability` | 日志时刻选中新回合模式的归一化概率。 | 是分配计划，不是本窗口实际占比。 |

**例子**：四种模式抽样概率均为 25%，前三种平均存活 6 s，蹲走只存活 1 s。
近似稳态下，蹲走步数占比约为 `1 / (6 + 6 + 6 + 1) = 5.3%`。
因此，失败回合很多也可能没有得到足够的有效训练时间。比例切换后还会残留旧回合，
不能要求 step_share 立即等于 sampling_probability。

排除指标位于 `Performance/task_command/excluded/`：

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `manual_episodes` | 执行过控制步，但没有自然终止条件便被重置的回合数。 | 普通无人值守训练应接近 0。 |
| `partial_episodes` | 自然结束，但观测步数、实际经历步数与回合计数不一致的回合数。 | 起始随机回合年龄可能造成首批出现；之后持续出现需检查计数和重置。 |
| `mixed_mode_episodes` | 完整观测且自然结束，但执行期间模式变化的回合数。 | 普通训练应为 0，人工控制可能出现。 |

排除原因互斥。空重置不计为回合；被排除回合的已观测控制步仍进入 step_count。

## 3. 任务条件：是在同样难度下比较吗

### 实际指令与扰动

以下指标使用 `Performance/task_command/<mode>/` 前缀。

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `height_offset_m` | 本窗口高度指令相对默认骨盆高度的平均偏移，按控制步加权，m。 | 越负通常表示蹲得越深；正负可能抵消，均值不反映极端蹲深。 |
| `command_speed_xy_mps` | 本窗口 XY 速度指令范数均值，按控制步加权，m/s。 | 越大通常要求更快运动；不是实际速度。 |
| `command_yaw_abs_radps` | 本窗口 yaw 指令绝对值均值，按控制步加权，rad/s。 | 越大通常要求更强转向能力。 |
| `disturbance_count` | 上肢随机目标事件触发的环境次数；一次事件同时作用双臂和腰部，计一次。 | 判断是否真正遇到扰动；短命且触发少，不能证明鲁棒性好。 |
| `disturbance_hz` | 触发次数 / 该模式本窗口累计观测控制秒数。 | 是多环境合并暴露率，需跨窗口看趋势。 |
| `disturbance_arm_fraction` | 实际触发事件使用的双臂扰动比例均值。 | 越大表示目标范围越宽；无事件时不输出，不代表实际力矩或运动幅度。 |

扰动比例是默认关节姿态到限位余量的比例，当前触发间隔随机取 1.5～3.0 s。
一次触发与后续影响可能跨窗口，不能只凭同窗口事件数推断失败因果。
这些指标不直接测量外力、冲击或每环境的质量、摩擦随机值。

### 当前任务范围

前缀为 `TaskDistribution/task_command/`，记录日志时刻的条件，而非窗口均值。

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `phase` | 当前阶段，1/2/3。 | 跨阶段条件不同，不直接用总奖励判断能力升降。 |
| `curriculum_control_steps` | 累计逻辑控制步数，包含续训进度。 | 默认每约 50 步对应一次 PPO 迭代；不乘并行环境数。 |
| `height_offset/lo`、`height_offset/hi` | 高度偏移采样上下界，m。 | 下界降低表示允许更深下蹲；并非各模式都会用全部范围。 |
| `lin_vel_x/lo`、`lin_vel_x/hi` | 前后速度采样上下界，m/s。 | 扩大后误差暂时上升，可能是任务变难。 |
| `lin_vel_y/lo`、`lin_vel_y/hi` | 侧向速度采样上下界，m/s。 | 用于解释侧向运动难度。 |
| `ang_vel_z/lo`、`ang_vel_z/hi` | 转向角速度采样上下界，rad/s。 | 与实际转向指令强度一起看。 |
| `pelvis_offset_x/lo`、`pelvis_offset_x/hi` | 骨盆前后偏移目标范围，m。 | 扩大后，静止模式的偏移跟踪要求提高。 |
| `pelvis_offset_y/lo`、`pelvis_offset_y/hi` | 骨盆左右偏移目标范围，m。 | 用于解释横向平衡任务难度。 |
| `disturbance_group_0_fraction` | 当前双臂扰动比例。 | 与触发次数及各模式生存表现一起看。 |
| `disturbance_group_1_fraction` | 当前腰部扰动比例。 | 同上；事件关闭时不输出，缺失不等于比例为 0。 |

采样边界不是实际目标极值；蹲走还受高度—速度包络限制。
跨运行比较应统一阶段、模式、指令范围、扰动和评估条件。

## 4. 课程信号：为什么训练条件变化

这些是课程判定状态，不等同于当前窗口的逐模式性能。

| 完整指标路径 | 定义 | 当前默认判断 |
| --- | --- | --- |
| `Curriculum/command_range/height_success` | 各环境最近有效完成回合的高度成功标志均值，混合所有模式。 | > 0.99 时具备扩大高度范围的条件，还需等到检查时间。 |
| `Curriculum/command_range/vel_success` | 最近有效行走、蹲走回合的速度成功标志均值。 | > 0.95 时具备扩大速度范围的条件，不保证下一帧立即扩大。 |
| `Curriculum/upper_body_disturbance_magnitude/survival_ema` | 有效完成回合存活比例的指数移动平均。 | > 0.95 时具备增加双臂扰动的条件，变化慢于当前窗口均值。 |
| `Curriculum/upper_body_disturbance_magnitude/survival_valid` | 生存 EMA 是否已经由有效窗口初始化，0/1。 | 为 0 时，不把 survival_ema=0 解释为全部失败。 |
| `Curriculum/upper_body_disturbance_magnitude/survival_episodes` | 生存课程累计纳入的有效回合数，可包含恢复历史。 | 与 EMA 一起判断数据基础，不是当前窗口 episode_count。 |
| `Curriculum/squat_walk_mode_introduction/introduced` | 蹲走是否已引入，0/1。 | 0→1 是任务变化点；当前约累计 400000 控制步触发，不代表已学会蹲走。 |

表现下降会暂停部分课程推进，但不会自动降低已达到的难度。
模式比例变化也会影响混合统计，课程成功率不宜单独用于比较模型性能。

## 5. PPO 与训练效率：优化是否正常

| 指标 | 定义 | 判断 |
| --- | --- | --- |
| `Train/mean_reward` | 最近 100 个结束回合的总回报均值。 | 同条件下持续提高通常有利；受存活、模式比例、难度和权重影响。 |
| `Train/mean_episode_length` | 最近 100 个结束回合的长度均值，单位控制步。 | 默认完整回合约 360 步；与逐模式 episode_length_s 的单位、窗口不同。 |
| `Loss/value` | 价值函数平均拟合损失。 | 关注持续爆增或非有限值；奖励尺度和难度变化也会抬高它，不要求单调下降。 |
| `Loss/surrogate` | PPO 裁剪代理目标对应的平均损失。 | 可正可负；受优势归一化影响，不能直接按更负或更接近 0 判断优劣。 |
| `Loss/entropy` | 策略动作分布平均熵。 | 名称虽含 Loss，数值是熵；与标准差一起看探索变化，不是越低越好。 |
| `Loss/learning_rate` | 优化器当前学习率。 | 当前按策略 KL 自适应调整；任务不变时突降，检查是否伴随学习率明显上升。 |
| `Policy/mean_std` | 策略各动作维度标准差均值。 | 高表示更强探索；骤增伴随抖动或骤降伴随学习停滞均值得检查。不是关节角噪声的直接读数。 |
| `Perf/total_fps` | 并行环境合计控制步数 / 采样与学习总耗时。 | 衡量吞吐，不是单环境仿真频率或策略质量；在相近硬件和环境数下比较。 |
| `Perf/collection_time` | 一次迭代采样耗时，s。 | 升高时关注仿真、传感器、渲染和重置开销。 |
| `Perf/learning_time` | 一次迭代策略更新耗时，s。 | 升高时关注网络计算、批次规模和优化配置。 |

## 6. 奖励分解：策略在优化什么

前缀为 `Episode_Reward/`。数值包含奖励权重与控制 dt，是回合累计贡献除以最大回合时长，
再按上游日志口径汇总；不是原始物理误差，也不是各模式等权的性能分数。
提前失败、模式比例及奖励启用条件都会影响数值。

正奖励通常希望提高，非正惩罚通常希望接近 0；但**为 0 也可能是该模式没有启用这一项**。
不要以牺牲任务完成率为代价，单独追求惩罚最小。

| 指标后缀 | 定义 | 判断 |
| --- | --- | --- |
| `alive` | 未发生失败终止时的存活奖励。 | 随稳定存活改善通常升高，但不证明完成任务。 |
| `terminating` | 非超时终止惩罚。 | 应趋近 0；明显变负时查看逐模式失败原因。 |
| `track_pelvis_height` | 高度误差的指数跟踪奖励。 | 越高通常越好，与 error_height_m 对照。 |
| `track_velocity` | 前后、侧向、yaw 三个速度通道的指数奖励之和。 | 较高可能由其中两个通道贡献，仍需查看具体误差。 |
| `track_pelvis_xy` | 站立/下蹲的骨盆水平偏移跟踪奖励。 | 结合骨盆误差看；静止模式占比减少也会使它下降。 |
| `leg_synergy` | 静止模式下髋膝踝俯仰角偏离协同平面的惩罚。 | 趋近 0 表示偏离较小，不保证平衡或全部联动正确。 |
| `hip_default_deviation` | 近站立高度、静止模式下髋 yaw/roll 偏离默认角度的惩罚。 | 趋近 0 通常更接近参考；低高度或行走时可能未启用。 |
| `ankle_default_deviation` | 同样条件下踝 pitch/roll 偏离默认角度的惩罚。 | 不应为了接近 0 而压制必要的平衡补偿。 |
| `hip_yaw_soft_deviation` | 静止模式下髋 yaw 超出默认角度死区的惩罚。 | 明显变负时检查脚尖外撇或扭转；死区内为 0。 |
| `flat_orientation` | 机体偏离直立姿态的惩罚。 | 趋近 0 通常更直立，但不保证动态平衡。 |
| `vertical_bounce` | 根节点竖直速度平方惩罚。 | 变负时检查跳动；下蹲过渡也需要竖直运动。 |
| `tilt_wobble` | 根节点 roll/pitch 角速度平方惩罚。 | 明显变负时检查晃动和恢复过程。 |
| `feet_ground_parallel` | 静止模式中持续接触脚的足底角点高度方差惩罚。 | 趋近 0 通常更贴平地面；无有效接触也可能为 0。 |
| `feet_slip` | 接触脚水平滑动速度惩罚。 | 趋近 0 通常滑移更少，但需确保不是靠停止行走获得。 |
| `feet_parallel` | 近站立高度、静止模式下两脚不平行的几何惩罚。 | 趋近 0 表示更符合约束，不直接评价转向步态。 |
| `feet_contact_forces` | 脚部接触力超出阈值的惩罚。 | 变差时检查落脚冲击或异常接触。 |
| `no_fly` | 至少一只脚接触的奖励。 | 较高表示更多时刻有脚接触，不保证稳定承重或左右脚正确交替。 |
| `stand_still` | 静止模式下脚离地的惩罚。 | 趋近 0 通常表示较少原地抬脚。 |
| `feet_gait_phase` | 行走/蹲走接触与反相步态时钟的匹配奖励。 | 较高表示节律更匹配，不替代速度、净空和滑移评价。 |
| `feet_lateral` | 两脚横向距离过窄或近站高时过宽的惩罚。 | 虽用正权重，输出仍非正；接近 0 表示未违反距离约束。 |
| `knee_lateral` | 两膝横向距离过窄或近站高时过宽的惩罚。 | 同上；结合回放检查夹膝或过度展开。 |
| `action_rate` | 相邻动作变化平方惩罚。 | 趋近 0 通常更平滑；过小也可能是不愿动作。 |
| `action_smoothness` | 动作二阶差分平方惩罚。 | 明显变负时检查动作来回抖动。 |
| `dof_torques` | 按标称刚度归一化后的下肢力矩平方惩罚。 | 同等任务完成能力下，更接近 0 通常表示用力更节省；不是功率或能耗。 |
| `dof_pos_limits` | 下肢关节超出软位置限位的惩罚。 | 应尽量接近 0；变差时检查极端姿态和动作幅度。 |
| `dof_torque_limits` | 显式下肢执行器裁剪前力矩超过上限的惩罚。 | 应尽量接近 0；持续变负提示频繁触及力矩约束。 |
| `dof_vel_limits` | 下肢关节速度超出配置软速度限制的惩罚。 | 应尽量接近 0；结合动作平滑与关节运动回放排查。 |

## 7. 常见曲线组合：下一步看什么

| 现象 | 初步解释 | 下一步 |
| --- | --- | --- |
| 总奖励提高，joint_success_rate 没提高 | 奖励改善未转化为任务完成，或模式分布改变。 | 看逐模式误差、失败率和奖励分解，检查是否只学会容易部分。 |
| 跟踪成功率高，failure_rate 也高 | 短回合跟踪尚可，但不能稳定存活。 | 先定位 termination 原因，不以跟踪成功率判定学会。 |
| timeout_rate 高，joint_success_rate 低 | 能活到时限，但任务不准确。 | 看高度、速度、yaw，以及静止模式的骨盆误差。 |
| step_share 很低，episode_length_s 也短 | 该模式频繁失败，实际样本不足。 | 对照采样概率、结束回合数和失败原因。 |
| 引入蹲走后总奖励下降，原有模式误差稳定 | 可能是组合任务和混合比例变化。 | 分别看蹲走与其他模式，不直接判定整体退化。 |
| 扰动变强后失败率升高 | 可能是鲁棒性尚未跟上。 | 看实际触发次数，在同样扰动条件下比较检查点。 |
| 所有模式突降，任务条件基本不变 | 可能是优化异常、数值问题或仿真变化。 | 检查学习率、标准差、损失及回放，不只凭曲线定因。 |
| FPS 下降，误差和成功率稳定 | 更像运行效率问题。 | 比较 collection_time 与 learning_time，区分采样和更新瓶颈。 |
| 无新误差点，episode_valid=0 | 没有新有效回合。 | 等待后续窗口，检查实际步数和排除计数。 |

比较检查点时，优先统一模式、指令难度、扰动与评估条件。
训练曲线用于定位问题，最终通过多回合回放或一致条件的评估确认。
