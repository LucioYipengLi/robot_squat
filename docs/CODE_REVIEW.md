## R10：是否增加躯干显式约束

**状态：待仿真评估，不直接增加奖励。**现有姿态奖励只约束根姿态，不能保证 torso 始终直立。

腰部由外部扰动和高刚度 PD 驱动，不属于策略动作空间。强罚躯干水平可能与合法腰部命令冲突，因此建议记录 torso 倾角、持续超限时长、跌倒率及腰部命令/跟踪误差之间的关系。若根姿态正常但 torso 持续过倾并影响表现，再比较有/无小权重、带死区的软惩罚。阈值应覆盖合法扰动，不先增加硬终止。

## V01：标称归一化后的力矩奖励量级

`dof_torques` 当前计算 `Σ(τ / K_nominal)²`，权重仍为 `-2.5e-6`。例如一个踝关节力矩为 20 N·m、标称刚度为 20，归一化平方为 1，其加权贡献仅为 `-2.5e-6`，奖励管理器随后还乘控制 dt。不能直接沿用上游“未归一化力矩平方”的权重经验判断其有效性。

**后果：**可能削弱力矩正则，属于待测量级问题，不是归一化公式错误。建议比较实际训练中该项与动作平滑、速度跟踪等奖励的均值和分位数，再决定权重。
